# Setup Guide

> **This guide explains how to set up and run the Mission Readiness & Predictive Maintenance Copilot locally on Windows.**

## Prerequisites

Before you begin, ensure you have the following installed:

- [ ] Windows 10/11
- [ ] Latest Python version
- [ ] Node.js
- [ ] PostgreSQL
- [ ] Docker Desktop
- [ ] IBM Bob AI access/configuration, if required by the implementation
- [ ] Git

> **Note:** The current prototype is not deployed and runs locally.
